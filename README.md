# README

Данный проект представляет собой in-memory key-value хранилище, реализованное на C++.
Серверная часть построена на базе библиотеки Boost.Asio и использует TCP-сервер для обработки клиентских соединений.

Сервер работает в многопоточном режиме:
каждое новое входящее соединение распределяется между рабочими потоками по принципу round-robin. Внутри каждого потока обработка клиентов выполняется асинхронно, что позволяет эффективно масштабироваться под большое количество одновременных подключений.

## Команды

-   `PUT <key> <value>` --- сохранить значение
-   `GET <key>` --- получить значение
-   `DEL <key>` --- удалить ключ
-   `COUNT` --- количество ключей
-   `DUMP <filename>` --- сохранить данные в указанный файл
-   `LOAD <filename>` --- загрузить данные из указанного файла
-   `EXIT` --- выход из программы

## Пример

    PUT name Vasya
    OK

    GET name
    OK Vasya

## Сборка
```bash
chmod +x build.sh
./build.sh
```
## Запуск
Server:
```bash
./build/kv_storage -p <port>
```
Client:
```bash
./build/client -a <address> -p <port>
```
